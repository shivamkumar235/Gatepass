# LogiGate Dispatch System (MERN + Tailwind)

## Requirements
Node.js 18+ and MongoDB running locally (or change MONGO_URI in backend/.env).

## Run (open 2 terminals in VS Code: Ctrl + `)

Terminal 1 - Backend
    cd backend
    npm install
    node server.js        -> http://localhost:5000

Terminal 2 - Frontend
    cd frontend
    npm install
    npm run dev           -> http://localhost:5173

Sample data (GP-1001 to GP-1004) is added automatically on first run.
